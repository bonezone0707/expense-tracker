# Expense Tracker
Project Description

The Purpose of Expense Tracker is to create a web-based application for users to record their personal financial information. It is intended as a personal finance manager that will enable the user to save, categorize and view information about spending habits and reports about budgets.

Developing a software engineering final project using Python and Flask.

Technology

The program will be written in Python and the web framework used will be Flask. The data will be stored on SQLite which will be implemented as work on the project develops.  The UI will be created using HTML and CSS and the version control will be carried out with Git and GitHub.

Current Features

The initial project is the setup of the Flask application and a working home page.

The rest will be implemented as the project progresses:  user accounts, expenditures, budgets, the dash-board functionality, reports, and automation.

How to Run

First, install the required Python packages:

pip install -r Flask==3.1.1

Then start the Flask application:

python application.py

Open a web browser and go to:

http://127.0.0.1:5000

The Expense Tracker welcome page should appear.
